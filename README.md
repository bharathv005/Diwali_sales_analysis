# 🪔 Diwali Sales Analysis

## 📋 Overview
This project analyzes sales data from a Diwali festival season to uncover customer purchasing patterns, demographic insights, and product performance.  
Using Python and popular data analysis libraries, this notebook explores how sales vary across gender, age groups, states, occupations, and product categories.

## 🎯 Objective
- Understand customer behavior during Diwali sales
- Identify top-performing products and customer segments
- Derive insights that can help optimize future sales campaigns

## 🧰 Tools & Libraries Used
- **Python**
- **NumPy**
- **Pandas**
- **Matplotlib**
- **Seaborn**
- **Jupyter Notebook**
